VLAN + trunkVLAN + trunk

Two switches share VLAN 10 (Staff) and VLAN 20 (Guests) over an 802.1Q trunk. Hosts in the same VLAN can reach each other; different VLANs cannot, because there is no router here.Două switch-uri partajează VLAN 10 (Staff) și VLAN 20 (Guests) printr-un trunk 802.1Q. Host-urile din același VLAN se văd; cele din VLAN-uri diferite, nu — în laborator nu există un rutier.

OSPF, single areaOSPF, o singură zonă

Three routers in area 0 become neighbors, advertise their loopbacks, and can ping 1.1.1.1, 2.2.2.2 and 3.3.3.3. The network command is a filter for interfaces, not a static route.Trei rutiere din area 0 devin vecini, își anunță loopback-urile și pot da ping la 1.1.1.1, 2.2.2.2 și 3.3.3.3. Comanda network e un filtru de interfețe, nu o rută statică.

Standard and extended ACLACL standard și extins

A standard ACL can block the whole Guest network from reaching Staff (placed close to the destination). An extended ACL can allow only HTTP to 192.168.10.10 and deny the rest (placed close to the source). Use one variant at a time.Un ACL standard poate bloca toată rețeaua Guest spre Staff (pus aproape de destinație). Unul extins poate lăsa doar HTTP către 192.168.10.10 și interzice restul (pus aproape de sursă). Se aplică o singură variantă pe rând.

Key commandsComenzi cheie
access-list 10 deny 192.168.20.0 0.0.0.255
ip access-list extended GUEST_TO_STAFF
 permit tcp 192.168.20.0 0.0.0.255 host 192.168.10.10 eq 80
ip access-group GUEST_TO_STAFF in
